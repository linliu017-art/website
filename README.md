# 我的个人主页

一个简洁的个人主页，用来介绍自己、展示项目和分享联系方式。页面采用原生 HTML 和 CSS 编写，适配桌面与手机屏幕，无需安装依赖或构建。

## 页面内容

- **首页介绍**：姓名和简短的个人介绍。
- **关于我**：职业、兴趣及正在探索的方向。
- **我的项目**：项目展示与说明。
- **保持联系**：邮箱、GitHub 或其他社交主页链接。

目前页面包含占位内容，可以按需替换为自己的信息。

## 本地查看

克隆仓库后，用浏览器直接打开 `index.html` 即可。

```bash
git clone https://github.com/linliu017-art/website.git
cd website
```

也可以在项目目录启动本地静态服务器（需已安装 Python 3）：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。按 `Ctrl+C` 停止服务器。

## 修改内容

所有页面内容和样式都位于 `index.html`：

- 修改 `<title>` 和页面描述，设置网站名称与简介。
- 在 `#home` 和 `#about` 中填写姓名、自我介绍。
- 在 `#projects` 中编辑或添加项目卡片。
- 在 `#contact` 中添加真实的联系方式和链接。
- 在 `<style>` 的 `:root` 中调整文字色和主题色。

保存文件后刷新浏览器，即可查看修改。
